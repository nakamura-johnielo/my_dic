- Esp-Jpn / Jpn-Espの更新inputとRepository inputを同じ差分更新契約へ変更した。

- 変更fieldがないcommandは、timestampを進めないno-opとして扱うようにした。
- 旧remote failureをlocal successとして扱う現行挙動はcharacterization testで固定し、retry/outboxはLocal-first 5の対象として維持した。
