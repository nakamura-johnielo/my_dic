## 実施内容

1. `FirebaseAuthDao` から refresh token の参照、Firebase `User` と provider 情報の一括ログ、sign-in 時の認証情報ログを削除した。
2. Auth DTO、auth effect、user profile、Firebase status DAO から email、account ID、user ID、device ID、生の Firestore document、生例外を含み得るログを削除した。
3. 残す認証ライフサイクルログを値なしの `AppLogger.event` へ置き換えた。失敗時は生例外ではなく `errorType` のみを記録する。
4. `AppLogger.event` に構造化 context と再帰的 redaction を追加した。token、password、Authorization、credential、secret、cookie、email、UID、account/user/device ID をキー単位で伏せる。
5. redaction 単体テスト、機密値をログ API へ渡すコードのソース検査、Firebase refresh token 参照の禁止検査を追加した。
6. `FirebaseAuthRemoteDataSource` の sign-in と sign-out が従来どおり DAO へ委譲される回帰テストを追加した。
